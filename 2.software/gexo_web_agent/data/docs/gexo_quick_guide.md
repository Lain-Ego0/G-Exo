# G-Exo 操作与安全速查

## 工作模式

G-Exo 有两种工作模式：

- 助力模式（ASSIST）：控制器生成基础力矩，全局助力比例统一缩放四个关节的助力。
- 阻尼训练模式（DAMPING）：电机进入阻尼和保护状态，不需要运行 PPO 或 TCN 推理。

请使用“阻尼训练模式”这一名称，不要称为“阻抗模式”。

## 调节助力

助力比例范围是 30% 到 100%。每次只能增加或减少 10%，四个关节必须一起调整，不能单独调整某一个关节。

阻尼训练模式下不能调节助力。助力比例已经达到 100% 时不能继续增加，达到 30% 时不能继续减少。

## 模式切换与安全条件

切换工作模式必须由用户再次确认，并且设备必须处于静止状态。

急停已触发、设备存在故障、CAN 离线或状态数据失联时，系统必须拒绝写操作。命令只有在控制器返回确认后才能报告成功；等待超时应报告失败，不能自动重试。

Web Agent 只允许查询状态、切换模式、调节全局助力和文档问答。它不能发送原始力矩、电流、CAN 帧或单关节命令，不能解除急停，也不能修改安全、滤波或控制器参数。
