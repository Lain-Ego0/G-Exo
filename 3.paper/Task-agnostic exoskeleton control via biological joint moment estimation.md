# Task-agnostic Exoskeleton Control via Biological Joint Moment Estimation

> **来源**: Nature | Vol 635 | 14 November 2024 | 337–344  
> **作者**: Dean D. Molinaro, Keaton L. Scherpereel, Ethan B. Schonhaut, Georgios Evangelopoulos, Max K. Shepherd & Aaron J. Young  
> **机构**: Georgia Institute of Technology / X, The Moonshot Factory  
> **DOI**: https://doi.org/10.1038/s41586-024-08157-7

---

## 核心思想：任务无关（Task-Agnostic）的外骨骼控制

传统外骨骼控制器依赖**任务分类器**（识别走路、上楼梯、跑步等）→ 再调用对应任务的**预定义辅助力矩曲线**。这导致两个根本性缺陷：
- 无法处理**非结构化/瞬态运动**（侧步、踉跄、急停转身等）
- 任务种类爆炸——现实世界中人类动作无法穷举

本文的核心创新在于**绕过任务分类**，直接从一个**连续生理状态变量**出发：**人体生物关节力矩（biological joint moment）**。用一个深度神经网络从可穿戴传感器数据中实时估计髋、膝关节力矩，再将其按比例映射为外骨骼辅助力矩。

## 一、硬件系统：服装一体化髋-膝外骨骼

| 组件 | 细节 |
|------|------|
| **执行器** | T-Motor AK80-9 准直驱电机，髋/膝各一个，峰值力矩 15 N·m，矢状面驱动 |
| **传感器** | 6 个 IMU（大腿、小腿、足部）、髋/膝关节编码器、压力鞋垫（测垂直地面反力+压力中心） |
| **主控** | Raspberry Pi 4B，55 Hz 控制回路 |
| **协处理器** | NVIDIA Jetson Nano（运行神经网络推理），通过 TCP/IP 以太网与 RPi 异步通信 |
| **结构** | 碳纤维 + 3D 打印尼龙半刚性框架 + 定制纺织裤（零延展编织布传递力，低延展针织布覆盖关节） |
| **被动自由度** | 髋部可平移+旋转，允许外展/内收，不影响关节活动范围 |
| **总重** | 约 7 kg |

## 二、数据采集与标注

### 2.1 运动数据集
- **15 名健康参与者**，执行 **28 种活动**（66 种实验条件），分为三类：
  - **周期性（Cyclic）**：平地走、负重走、倒走、跑步、上下斜坡/楼梯等
  - **阻抗式（Impedance-like）**：蹲起、弓步、坐站、跳跃、提放重物、拔河等
  - **非结构化（Unstructured）**：急停急启、侧切、跨步、转身、漫步、扭体、推拉恢复等
- 同步采集外骨骼传感器数据 + **光学运动捕捉（Vicon, 200 Hz）** + **测力台（1000 Hz）**

### 2.2 真实标签生成
- 用 **OpenSim** 逆向运动学 + 逆向动力学，基于运动捕捉标记点位置和地面反力（GRF），计算出髋、膝关节的矢状面力矩作为 **ground truth** 标签
- 力矩按参与者体重归一化（单位 N·m·kg⁻¹）

### 2.3 数据采集三阶段
1. **Phase 1**（10 人）：外骨骼不助力或用手工设计的启发式控制器提供部分助力，收集无助力+有助力的传感器-力矩配对数据
2. **Phase 2**（5 人）：部署初步训练的力矩估计器，边助力边收集数据（使训练数据分布更接近最终部署状态）
3. **Phase 3**（10 人，含 3 名老参与者）：最终模型在线测试 — 力矩估计精度 / 代谢成本 / 下肢生物关节功

## 三、神经网络：时序卷积网络（TCN）

### 3.1 输入
单侧腿的传感器序列（上采样至 200 Hz 以匹配训练频率）：
- 髋/膝关节编码器角度
- 大腿、小腿、足部 6 轴 IMU 数据
- 压力鞋垫数据（垂直 GRF + 压力中心 COP）

所有输入经过 Z-score 标准化（均值/标准差来自训练集）。

### 3.2 输出与架构
- **双输出头**：同时估计髋关节和膝关节的**总力矩**（人体生物力矩 + 外骨骼力矩之和）
  - 选择估计总力矩而非纯生物力矩，是为了保持传感器→力矩映射关系不随控制器参数变化而改变
  - 部署时：生物力矩 = 网络输出总力矩 − 上一时刻测得的实际执行器力矩
- 采用 Bai et al. 提出的 TCN 架构，针对关节力矩估计做了适配

### 3.3 超参数优化（两阶段）
1. **Stage 1**：在先前收集的 12 人大规模数据集上用 Vizier 做贝叶斯优化，搜索 11 维超参数空间，训练 >10,000 个模型
2. **Stage 2**：用实际外骨骼 Phase 1+2 数据做网格搜索微调，锁定最敏感的 6 个超参数，再训练 1,440 个模型

最终超参数相对先前工作提升了 8% 的 MAE。

### 3.4 髋力矩延时估计技巧
- 因为控制器会对髋力矩估计值额外延迟 50 ms（见下文），网络被训练为**预测未来 50 ms 后的髋力矩**（输出标签在时间轴上提前 50 ms），比直接估计当前力矩提升了 ~5% 的 MAE

## 四、训练任务选择：前向选择算法

一个关键实现细节：人力标注 28 种活动的成本极高，是否必须全标注？

**前向任务选择（Forward Activity Selection）**：
- 起始：只用**平地走路**训练模型，在所有任务上测试
- 每轮迭代：逐一尝试将每个候选任务加入训练集，计算模型在**其他所有任务**上的相对改进分数 `s_i[g]`
- 选择带来最大泛化改进的任务加入训练集，重复

**关键发现**：
- 只需 **7 个任务**即可达到泛化饱和（>95% 的总改进量）
- 泛化最关键的任务（除种子任务平地走外）：**静态站立姿势**（使网络学到人体静态特性——站立时关节力矩接近零）、**跳跃**和**侧切**（帮助确立系统动态边界）
- 需 **19 个任务**才能使综合精度接近全量训练（误差在全量训练的 5% 以内）

最终模型在 19 个任务上训练，9 个任务完全未见过，在线测试时对 hold-out 任务的泛化 R² 仍达到 0.83（髋）和 0.85（膝）。

## 五、从力矩估计到外骨骼指令：连续力矩映射

力矩估计值经过三步连续变换生成外骨骼指令力矩：

```
关节力矩估计 → [比例缩放] → [延时] → [低通滤波] → 指令力矩
```

| 步骤 | 髋关节 | 膝关节 | 原因 |
|------|--------|--------|------|
| **缩放** | 估计生物力矩 × 20% | 估计生物力矩 × 15% | 试点实验确定，兼顾舒适度与电机不饱和过热 |
| **延时** | 100 ms（= 系统最小时延 50 ms + 额外 50 ms） | 50 ms（系统最小时延） | 延时可最大化外骨骼做的正功，降低用户代谢消耗；膝采用最小延时基于用户偏好测试 |
| **低通滤波** | 二阶 Butterworth，10 Hz 截止频率（额外增加 25 ms 延时） | 同左 | 保留人体运动频率成分，去除估计器的抖动 |
| **总延时** | ~125 ms | ~75 ms | — |
| **限幅** | 峰值扭矩 ≤15 N·m | ≤15 N·m | 保护硬件 |

## 六、基线对比方法

构造了一个理论**最优基线方法**（离线计算，假设完美条件）：

- **周期性任务**：用任务完美分类 + 完美步态相位 → 查表读取该任务的用户平均关节力矩曲线（spline/阻抗参数拟合）
- **阻抗式任务**：用 stance/swing 状态机（基于 GRF 判断）→ stance 期用线性弹簧-阻尼模型（刚度 5 N·m·rad⁻¹，平衡角 0°），swing 期设为零力矩
- **非结构化任务**：基线方法无法处理（从略）——这恰是分类式控制器的核心缺陷

> 注意：该基线拥有"完美预测的 28 类任务分类器"这一不可能条件，代表分类式方法理论的**上界**。现实中分类器和步态相位估计还有额外误差。

## 七、评估体系

### 7.1 力矩估计精度（10 人在线测试）

| 指标 | 周期性 | 阻抗式 | 非结构化 |
|------|--------|--------|----------|
| 髋 R² | 0.79 | 0.81 | 0.80 |
| 膝 R² | 0.86 | 0.87 | 0.82 |
| 髋 RMSE | 0.15 Nm·kg⁻¹ | 0.21 | — |
| 膝 RMSE | 0.13 Nm·kg⁻¹ | 0.16 | — |

- 相比基线方法：周期性任务髋 R² 提升 19%，膝 R² 提升 40%；阻抗式任务髋 R² 提升 63%，膝 R² 提升 57%
- 大规模欠估计/过估计分布：均值接近零（髋 −2.7%，膝 −1.3%），标准差仅 7.8%/6.6%

### 7.2 人体效能评估

**代谢成本**（4 种任务，对比 zero torque 条件）：
- 平地走 −8.0%，负重提放 −8.0%，5°上坡走 −19.7%，跑步 −13.7%（均显著）
- 变速变坡度电路（模拟真实步行片段）：−12.9%

**下肢生物关节正功**（6 种任务，对比 zero torque）：
- 坐站 −15.7%，上楼梯 −5.3%，蹲起 −12.3%，弓步 −8.9%，提放重物 −13.1%，登台阶 −7.3%（均显著）

### 7.3 泛化到全新任务

3 位参与者额外完成 8 种完全未训练过的任务（如 burpee、摸拟篮球上篮、分带跑步机等）：
- 典型人体运动泛化良好
- 极端动态行为（如手撑地将体重移离下肢）预测形状和幅度失准（R² 0.24–0.92），但仍方向正确

## 八、传感器重要性分析

通过传感器消融/丢落实验：
- **IMU 贡献最大**（因运动学信息可间接推断 GRF），编码器次之，压力鞋垫最后
- 去除 GRF/COP：髋 R² −0.03，膝 R² −0.07
- 任一传感器丢失都导致显著精度下降，说明网络学习了依赖全部传感器

## 总结：该方法的完整实现链路

```
[多传感器数据] → [TCN估计髋膝力矩] → [减去执行器力矩→生物力矩]
    → [缩放 20%/15%] → [延时 100/50 ms] → [10 Hz低通滤波] → [指令力矩]
    → [执行器输出] → [与人体耦合，降低生物关节力矩和代谢成本]
```

### 核心工程决策的理性逻辑

1. **选 TCN 而非 LSTM/Transformer**：时序卷积的因果性和感受野控制适合实时控制
2. **输出总力矩而非纯生物力矩**：解耦模型训练与具体控制器参数
3. **前向任务选择**：用最少标注成本逼近全量训练精度
4. **延时策略差异化（髋多延 50 ms）**：基于生物力学——髋助力延时更大可做更多正功
5. **先估计后滤后助力**：保证力矩估计的生理合理性和用户舒适度
