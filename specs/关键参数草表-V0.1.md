## 一、总体指标

| 参数 | 目标值 | 备注 |
|------|--------|------|
| 产品定位 | 消费级四自由度主动式下肢外骨骼 | 户外徒步为主，慢跑/爬山兼容 |
| 整机重量 | **≤4 kg**（不含电池） | 电池外置，充电宝供电 |
| 穿戴方式 | 独立穿脱，腿部绑带 + 腰部快拆卡扣 | |
| 目标用户体重 | 50-90 kg（可调绑带适配） | 70 kg 为参考设计值 |
| 机身材料 | 铝合金（承力件）+ 碳纤维管（连杆）+ 尼龙（绑带） | |

## 二、自由度分配

| 关节 | 方向 | 类型 | 驱动 | 数量 |
|------|------|------|------|------|
| 髋关节 | 矢状面屈曲/伸展 | **主动** | 电机直驱 | 2（左右） |
| 膝关节 | 矢状面屈曲/伸展 | **主动** | 电机直驱 | 2（左右） |
| 髋关节 | 冠状面外展/内收 | **被动** | 套环 + 腰带滑动 | 2（左右） |
| 髋关节 | 旋转 | **不提供** | — | — |
| 踝关节 | — | **不做** | — | — |

> **主动自由度合计：4**（髋屈伸×2 + 膝屈伸×2）  
> **被动自由度合计：2**（冠状面外展/内收×2）

## 六、能源系统

| 参数 | 目标值 | 备注 |
|------|--------|------|
| 供电方案 | **USB-PD 充电宝** 20V 输出 | 单充电宝，后续支持热插拔换弹 |
| 电压平台 | 20V（PD 诱骗）→ 直驱电机 | 无需升压模块（电机 15-60V 宽输入） |
| 辅助电源 | 20V → 降压 5V/3.3V → 主控 + IMU | |
| 整机功率 | **25-60W**（三档可调） | |
| 充电宝容量 | 20000mAh (≈74Wh) ×1-2 个 | |
| 续航估算 | 25W 档 ≈3h / 40W 档 ≈1.8h / 60W 档 ≈1.2h | 单充电宝 74Wh |
| PD 热插拔 | 需 PD 热插拔管理器 | |

### 功率档位-场景对应

| 档位 | 整机功率 | 适用场景 | 助力感受 | 续航（74Wh） |
|------|----------|----------|----------|-------------|
| 低 | ~25W | 平地步行 | 轻微辅助 | ~3h |
| 中 | ~40W | 慢跑 | 中等辅助 | ~1.8h |
| 高 | ~60W | 户外爬山/上坡 | 最大辅助 | ~1.2h |

## 七、控制策略

| 阶段 | 策略 | 说明 |
|------|------|------|
| **V1（黑客松）** | 电流估算力矩 + 导纳控制 | 零额外传感器成本，跑通硬件链路 |
| V2 | TCN 生物力矩估计 + 比例放大 | 参考 Nature 2024 论文，需采集训练数据 |
| V3（探索） | RL+AMP 端到端策略 | 仿真训练 + Sim2Real，中长期目标 |

### V1 导纳控制核心参数

| 参数 | 初始值 | 说明 |
|------|--------|------|
| 助力比例 | 15-20% | 髋 20% / 膝 15%（参考论文） |
| 导纳虚拟惯量 | 待标定 | 影响响应灵敏度 |
| 导纳虚拟阻尼 | 待标定 | 影响稳定性 |
| 力矩估计 | 电机电流 × 转矩常数 | 无额外力矩传感器 |

## 十、关键风险与依赖

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 🟡 灵足 4340 类似物跳票 | 无可用模组 | 备选：灵足 RS06（¥849, 9:1 减速比, 需额外降速机构） |
| 🟡 20V PD 供电不足（峰值电流） | 高功率档无法使用 | 先用中低档跑通 Demo，峰值电流加电容缓冲 |
| 🟢 4kg 重量超标 | 穿戴体验差 | 连杆减重（碳纤维）、精简绑带结构 |
| 🟢 RK3588 功耗过高 | 续航缩短 | 考虑低功耗备选（RK3566/Orange Pi 5） |
| 🟢 电流估算力矩精度不足 | 导纳控制不稳定 | 离线标定转矩常数，加低通滤波 |
