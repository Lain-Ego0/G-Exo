## 技术路线

基于 [Molinaro et al., Nature 2024](https://doi.org/10.1038/s41586-024-08157-7) 的任务无关控制范式 + sanholy 分支 RL 训练框架：

```
G354 IMU×4 + RS02 编码器 → K3/OPi5 Plus → TCN时序编码 + PPO策略推理 → CAN 力矩指令 → RS02×4
```

- RL + TCN 时序编码器混合架构：TCN 压缩传感器时序特征 → PPO 策略输出四关节力矩
- 仿真训练：MyoSuite 80 肌肉人体 + MuJoCo 物理引擎 + PPO（Stable-Baselines3）
- 同一控制器覆盖走路、跑步、深蹲、弓步、上下楼梯等 28+ 动作，无需任务分类器
- 辅助力矩：策略网络直接输出归一化力矩 → 缩放/延时/滤波/限幅 → CAN MIT 指令
